# Knowledge base files

- `wiki/` — pages generated by `backend/scripts/scrape_wiki.py` from The Hunger Games Wiki
  (Fandom, CC BY-SA 3.0) and Wikipedia (CC BY-SA 4.0). Each file keeps its source URL.
- `books/` — (git-ignored) put here PDF copies of the novels.

Load everything with: `docker compose exec backend python -m scripts.seed /data`
